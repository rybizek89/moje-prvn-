# Moje první repo

Ahoj! Toto je můj první repozitář na GitHubu. Učím se tu základy práce s GitHubem a ukládám sem jednoduché poznámky a ukázky.

Co tady najdeš
- README.md — tento soubor (popis projektu)
- uvod.md — krátký úvodní text
- issues — místo pro nápady a úkoly

Jak začít
1. Přečti si README a uvod.md.
2. Pokud máš nápad nebo úkol, vytvoř Issue (sekce Issues).
3. V případě jednoduché úpravy můžeš soubor upravit přímo přes web a potvrdit změny (Commit).
